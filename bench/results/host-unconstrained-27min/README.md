# 制限なしで測った 27 分（参考・判定に使わない）

2026-11-03。`bench/host-sample.mjs` の初版で、**メモリ制限をかけずに**ホスト（30 GB）で測ったもの。
途中で中断したため 27 分しかない。

```
175.80 → 188.70 MiB   傾き +11.18 MiB/時（単調増加）
```

この数値は漏れではなく、**V8 が利用可能メモリからヒープ上限を決める**ことの影響である。

| | V8 ヒープ上限 |
|---|---|
| 制限なし（このホスト） | 4288 MiB |
| `MemoryMax=350M` | 259 MiB |

制限がなければ GC が遅れ、RSS は天井に向かって伸び続ける。同じ待機状態を 350M 制限下で測ると
0.13 MiB/時 だった（`../host-6h/`）。**VPS の挙動を知るには制限下で測る必要がある**という記録として残す。
